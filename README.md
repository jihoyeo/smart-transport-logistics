# 스마트 교통물류

가천대학교 스마트시티학과 · 2026학년도 2학기 · 학부 3학년 (12주 과정)

## 학기 흐름

```
1주   환경 준비, 시뮬레이션 개요        ← 첫 시뮬레이션을 돌려 봅니다
2주   도로망 데이터
3주   최단경로 직접 구현                ← 다익스트라 · A*
4주   시간대별 속도, GTFS
5주   RAPTOR 직접 구현                  ← 대중교통 경로 탐색
6주   환승·요금·지표                    ← 기말 프로젝트 착수
7주   통행 수요, 결과 읽기
8주   휴강 (온라인 과제)
9주   중간시험
10주  ETA 예측, 배차·물류 최적화
11주  시뮬레이션 루프 직접 구현
12주  기말 프로젝트 발표
```
