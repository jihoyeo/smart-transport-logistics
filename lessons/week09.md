# 9주차 (10-27 화 중간시험, 10-28 수 해설·중간 점검)

교수자용 진행표.

- 화요일: 중간시험. 범위 교재 0~8장, 12장
- 수요일: 시험 해설 + 기말 프로젝트 중간 점검
- HW3 마감: 10-28(수) 수업 시작 전
- 9주차 프로젝트 산출물(개인): 조사 기반 시간대별 수요 프로파일, 현황 시뮬레이션. 마감 11-03(화) 수업 시작 전

## 화요일 — 중간시험 (100분)

| 시간 | 내용 |
|---|---|
| 0~5 | 좌석 배치, 노트북 전원, 사이버캠퍼스 접속 확인 |
| 5~40 | 단답형 (40%). 폐쇄형. 화면에 사이버캠퍼스만 |
| 40~45 | 단답형 제출 확인 후 코딩테스트 개방 |
| 45~95 | 코딩테스트 (60%). 제공 ipynb와 데이터. LLM 사용 가능. 채점은 실행 결과의 해석 문장 |
| 95~100 | 제출 확인. ipynb 파일 업로드가 늦는 학생은 이름을 적고 5분 연장 |

준비물: 시험용 ipynb는 `SMARTMOB_OFFLINE=1`로 돌아가게 만들어 둔다. 서버 접속이 안 되는 학생이 있어도 시험이 멈추지 않는다.

## 수요일 — 해설(50분), 중간 점검(50분)

| 시간 | 내용 | 화면 |
|---|---|---|
| 0~10 | HW3 제출 확인. 점수 분포 | — |
| 10~30 | 단답형 해설. 오답이 많은 문항 위주. 교재 해당 절을 열어 보여 줌 | 교재 |
| 30~50 | 코딩테스트 해설. 해석 문장에서 자주 빠진 것: 서비스율 없이 대기시간만, 평균만 보고 분포 없음 | 시험 ipynb |
| 50~90 | 개별 중간 점검. 체크리스트를 화면에 띄우고 각자 자기 상태를 표시하게 한 뒤, 막힌 항목이 많은 학생부터 순회 | 학생 노트북 |
| 90~100 | 9주차 산출물 마감(11-03 화)과 11주차 산출물(RAPTOR 대조표) 예고 | 공지 |

## 중간 점검 체크리스트 (개인)

- [ ] HW3 GTFS가 validate_feed를 통과했는가. 정류장 수, 노선 수, 운행 수
- [ ] 패턴 수가 운행 수보다 작은가 (같으면 순서 묶기 실패)
- [ ] 자기 RAPTOR로 O-D 세 건 질의 결과가 시간표 손 대조와 일치했는가
- [ ] 승하차 조사표에서 observed와 estimated 비율. 어느 시간대가 비어 있는가
- [ ] 수요 프로파일을 조사표에서 어떻게 만들 계획인가 (정류장별 승차 인원 × 시간대 → 8.4절 형식)
- [ ] 현황 시뮬레이션에 어떤 엔진을 쓸 계획인가. 자기 RAPTOR(고정노선) 또는 11장 루프(DRT 시나리오)
- [ ] 자기 시나리오가 무엇을 바꿀지 한 문장으로 말할 수 있는가
- [ ] 막힌 곳 하나

점검 결과는 `lessons/` 에 두지 않고 교수자 메모로 따로 적는다.
