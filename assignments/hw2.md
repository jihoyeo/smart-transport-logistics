## 시작하기 전에

질의할 정류장 쌍을 각자 정합니다. 학번 뒤 네 자리를 난수 씨앗으로 씁니다.

```python
import random
from smartmob.data import load_gtfs

feed = load_gtfs("hanam")
stop_ids = sorted(feed["stops"]["stop_id"])
rng = random.Random(int("여기에 학번 뒤 네 자리"))
my_pairs = [(rng.choice(stop_ids), rng.choice(stop_ids)) for _ in range(20)]
print(my_pairs[:3])
```

여기서 나온 스무 쌍이 A2와 B2의 질의 대상입니다. 사람마다 다르므로 결과도 다릅니다. 노트북 첫 셀에 이 코드와 출력을 그대로 넣어 주세요.
