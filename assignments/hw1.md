## 채점 방식

코드가 돌아가는지는 채점하지 않습니다. 그것은 교재 저장소의 자가 채점기가 봅니다.

채점하는 것은 세 가지입니다. 기준과 대조했는지, 나온 숫자를 읽은 문장이 있는지, 어긋난 값이 있을 때 원인을 설명했는지입니다.

AI 도구를 써도 됩니다. 오히려 쓰기를 권합니다. 다만 나온 코드를 이해하고 자가 채점이 실패했을 때 어디가 문제인지 찾을 수 있어야 합니다. C부에서 사용 기록을 함께 제출합니다.

## 시작하기 전에

기준 노드를 각자 정합니다. 학번 뒤 네 자리를 난수 씨앗으로 씁니다.

```python
import random
from smartmob.data import load_road_graph

G = load_road_graph("hanam", modes=("drive",))
rng = random.Random(int("여기에 학번 뒤 네 자리"))
my_node = rng.choice(sorted(n for n in G.adj if G.adj[n]))
print(my_node, G.coord[my_node])
```

여기서 나온 `my_node`가 B부의 출발 노드입니다. 사람마다 다르므로 결과도 다릅니다. 노트북 첫 셀에 이 코드와 출력을 그대로 넣어 주세요.

## A부 — 도로망 통계 (40점)

### A1. 도로 종류별 총 연장 (15점)

`highway` 종류별 총 연장을 킬로미터 단위로 구하고, 긴 순서로 상위 10개를 막대그래프로 그립니다. 한글이 깨지면 `smartmob.viz.use_korean_font()`를 먼저 호출합니다.

제출: 막대그래프 한 장, 상위 세 종류가 무엇이고 그것이 하남시 도로망에 대해 무엇을 말해 주는지 두세 문장.

### A2. 필터 전후 비교 (15점)

자동차가 다닐 수 있는 도로만 남기기 전과 후의 총 연장을 각각 구합니다. 두 값의 차이가 어떤 도로 종류로 구성되어 있는지 표로 냅니다.

제출: 필터 전 총 연장, 필터 후 총 연장, 차이를 구성하는 도로 종류 상위 5개 표, 그리고 이 필터를 적용하지 않고 자동차 최단경로를 구하면 어떤 경로가 나오는지 두 문장.

### A3. 인접 리스트 대조 (10점)

교재 2.4절대로 인접 리스트를 직접 만든 뒤, `load_road_graph("hanam", modes=("drive",))`의 노드 수와 엣지 수를 비교합니다.

제출: 두 값을 나란히 놓은 표. 값이 같으면 같다고 쓰고, 다르면 몇 개가 어떤 방향으로 다른지와 그 원인을 세 문장 이내로 설명합니다.

이 항목은 값이 달라도 감점하지 않습니다. 차이를 발견하고 원인을 설명하면 만점입니다. 대조하지 않고 넘어가면 0점입니다.

구현하면서 막혔던 지점 하나를 골라 무엇이 문제였고 어떻게 찾았는지 세 줄에서 다섯 줄로 씁니다. 자가 채점의 어느 항목이 실패했는지, 무엇을 출력해 보고 원인을 알았는지를 씁니다.

한 번에 통과했다면 그렇게 쓰고, 대신 경로 복원 부분이 왜 필요한지 설명합니다.

## C부 — 작업 기록 (20점)
